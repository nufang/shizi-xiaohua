# 糖果城堡识字页设计

## 目的

做一个幼儿园小朋友用的识字网页，画面和奖励面向小女孩。小朋友看图点汉字。过关后为自己的小公主选一件发饰或裙子，从而愿意继续认下一关。

成品是一个文件：`C:\Users\zhangq-bm\shizi-xiaohua\index.html`。双击即可打开。不安装，不联网，不建账号。

## 已定决定

- 玩法是看图点字。每次一张图、三个大字。
- 四关都从第一次打开就能进：小动物、花朵、水果、家人。每关 8 个字。
- 题目出现时朗读这个字一次。点对后再朗读一次。
- 点错会轻轻晃一下，留在这一题，不扣分，也不换题。
- 画面是糖果城堡：亮粉、紫色、金色。
- 认字过程中不换衣服。整关 8 个字都点对之后才打开衣橱。
- 衣橱里可以选这一关新得到的，也可以选以前得到的。发饰和裙子分开放。选发饰只换头上的，选裙子只换裙子。
- 必须点一件才回到城堡。点已经穿着的那一件，表示继续穿它。
- 已经过关的关卡可以再玩，再玩不发新衣服，也不再打开衣橱。
- 四关都过关后，礼花出现在城堡大门上。
- 进度保存在这台设备的浏览器里。

## 小朋友怎么玩

1. 打开页面就是城堡大门。小公主站在中间。第一次打开时，她穿着一条默认的浅色裙子，头上没有发饰。四扇门分别是小动物、花朵、水果、家人。过完的门上有一颗金星。
2. 点进一关后，8 个字打乱排队。认字页有一个返回城堡的按钮。中途返回不记住答到第几题，下次进入这一关会重新打乱。已经过关的记录保持不变。每一题显示对应的小图案和三个大字。三个字里有 1 个正确答案，另外 2 个从这一关其余的字里抽取，三个字的位置再打乱。上方有 8 个进度点，表示这一题是第几个。
3. 点错：被点的字晃一下，题目不变。点对：再读一遍，进度点亮一格，然后进入下一个字。8 个都点对才算过关。
4. 第一次过关：把这一关的 3 件奖励放进衣橱并打开衣橱。小朋友点一件，立刻穿上，回到城堡，该门出现金星。
5. 四扇门都有金星时，城堡大门播放礼花。任意一扇门仍可再玩。

## 关卡内容

图案画在网页里，不使用网络图片。

| 关卡 | 汉字 | 第一次过关得到的衣服 |
| --- | --- | --- |
| 小动物 | 猫、狗、鸟、鱼、兔、马、羊、熊 | 猫耳（发饰）、蝴蝶结（发饰）、蓬蓬裙（裙子） |
| 花朵 | 花、草、叶、树、桃、荷、兰、菊 | 花冠（发饰）、粉花夹（发饰）、花瓣裙（裙子） |
| 水果 | 果、梨、瓜、枣、杏、李、橘、莓 | 草莓夹（发饰）、樱桃夹（发饰）、糖果裙（裙子） |

## 网页结构

全部写在 `index.html` 里，样式和脚本不拆文件。页面内用各自独立的函数分工，互相对外只通过下面这些结果协作：

- **字库**：提供四关的汉字、图案和奖励。不读取进度。
- **进度**：读取和保存「过关了哪些、拥有哪些衣服、现在穿什么、衣橱是否还没选完」。不负责出题。
- **出题**：根据某一关和当前题号，给出这一题的正确答案和两个干扰字。不直接改画面。
- **朗读**：朗读一个汉字，并能停掉上一句。不判断对错。
- **画面**：城堡、认字、衣橱三块，按当前步骤显示其中一块。礼花是城堡大门上的一层，不是第四个页面。

保存键名是 `shizi-castle`。保存内容的形状是：

```json
{
  "clearedLevels": ["animals"],
  "ownedItemIds": ["cat-ears", "bow"],
  "equipped": { "hair": "bow", "dress": null },
  "wardrobePending": false
}
```

关卡编号是 `animals`、`flowers`、`fruits`、`family`。

奖励编号是：

| 编号 | 名称 | 位置 |
| --- | --- | --- |
| cat-ears | 猫耳 | 发饰 |
| bow | 蝴蝶结 | 发饰 |
| puff-skirt | 蓬蓬裙 | 裙子 |
| flower-crown | 花冠 | 发饰 |
| pink-clip | 粉花夹 | 发饰 |
| petal-skirt | 花瓣裙 | 裙子 |
| strawberry-clip | 草莓夹 | 发饰 |
| cherry-clip | 樱桃夹 | 发饰 |
| candy-skirt | 糖果裙 | 裙子 |
| crown | 小皇冠 | 发饰 |
| ribbon | 丝带 | 发饰 |
| princess-skirt | 公主裙 | 裙子 |

`equipped.hair` 或 `equipped.dress` 在还没选过时为 `null`。默认浅色裙子只用于显示，不算一件已获得的奖励，也不出现在衣橱里。

## 数据怎么走

1. 打开页面时读取 `shizi-castle`。读不到或内容无法识别时，按第一次打开显示。
2. 进入某一关时，把该关 8 个字打乱，固定成这一轮的顺序。中途点错不改变这个顺序。
3. 出题时朗读正确答案。点对后先停掉可能还在读的句子，再把这个字读第二遍，然后题号加一。
4. 题号走到 8：如果这关不在 `clearedLevels` 里，把 3 件奖励的编号加入 `ownedItemIds`，把这关写入 `clearedLevels`，把 `wardrobePending` 设为 `true` 并保存，然后打开衣橱。如果已经在里面，直接回城堡。
5. 在衣橱点一件：若是发饰，写入 `equipped.hair`；若是裙子，写入 `equipped.dress`。把 `wardrobePending` 设为 `false`，保存后回城堡。第一次打开衣橱时三件都还没穿过，点任何一件都会换上。以后如果点的是已经穿着的那一件，就保持现在的搭配。
6. 再次打开页面时，如果 `wardrobePending` 为 `true`，直接进入衣橱，不回到做到一半的题目。
7. 城堡根据 `clearedLevels` 画金星。四关都在里面时显示礼花。

同一题在「点对之后、第二遍朗读结束之前」不接收新的点击，避免一次点击被算成两题。

## 出错时

- 这台设备没有中文语音，或浏览器不能朗读：图和字照常出现，游戏可以继续点。角落给大人留一行小字：「这台设备读不出中文，仍然可以点字。」这行字不挡住三个大字。
- 朗读没有正常结束：1 秒后仍然进入下一题，避免停在点对之后。
- 出下一题之前先停掉上一句朗读。
- 浏览器不允许保存，或保存的内容损坏：这一次仍然能玩。刷新后按第一次打开。不弹出错误框。

## 验收

这一版用手动检查，不做自动测试。双击打开 `index.html`，确认：

- 点错会留在这一题，点对会再读一遍并进入下一个字。
- 第一次过关能选一件发饰或裙子。刷新后，这件衣服还穿着，对应的门上还有金星。
- 衣橱还没选衣服时刷新，再次打开仍然停在衣橱。
- 认字中途返回城堡，再进入同一关会重新开始这一轮，已有的金星不变。
- 已经过关的一关再玩完，不出现新衣服，也不打开衣橱。
- 四关都过关后，城堡大门上有礼花。
- 把窗口缩到手机宽度，三个大字仍然能用手指点到。
- 在没有中文语音的环境里，页面仍能点完一题，并出现给大人的那一行小字。

## 不做什么

不做拼音、笔顺、家长后台、多个小朋友档案、账号、联网字库、音效文件，也不在这一版增加第五关。
